What happens when you pay

in order
UnlockThe fingerprint is matched on the card. Only a yes or no leaves the sensor, and the chip stays live for 15 seconds.
Live codeOnline, the bank works out the same 3-digit code from a shared secret and the time, so a copied code expires.
ApproveThe bank asks the owner to approve that exact amount and shop, with their fingerprint.
WatchEvery attempt is logged, and the fraud monitor looks across the log for patterns a single decline can't show.
